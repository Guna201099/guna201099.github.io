How I work

Data is useless if you cannot get it out of the machine cleanly.

01

Get the signal out

Most data problems turn out to be hardware problems in disguise. A noisy bus, a late interrupt, a clock that resets when the power drops.

02

Clean it where it is measured

Fix broken rows, line every sensor up in time, put it somewhere you can ask questions of. A run should be ready to read in minutes.

03

Then let the model speak

Spot the moment the behaviour changes. Forecast against what the machine did before. This works because the input was trustworthy.
